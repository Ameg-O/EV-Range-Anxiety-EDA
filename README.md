This project explores electric vehicle (EV) adoption and range anxiety using Exploratory Data Analysis (EDA).
- Understand the factors influencing EV adoption.
- Explore range anxiety among potential EV buyers.
- Analyze the impact of charging infrastructure and government subsidies.
- Identify patterns and relationships in the dataset.
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab
- EV_Adoption_and_Range_Anxiety_EDA.ipynb — EDA analysis and visualizations.
- EV_Adoption_and_Range_Anxiety_Dataset.csv — Dataset used for analysis.
